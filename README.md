# ToDo 2

A simple React to-do application built with Vite. It lets a user create tasks, mark them as complete, edit descriptions, and delete items from the list.

## What this app does

- Add a new task from the input field
- Mark a task as done with a checkbox
- Edit an existing task description
- Delete a task after confirmation
- Filter tasks by All, Done, and Pending
- Keep task order with completed items sorted to the first and newly added to last


## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```
